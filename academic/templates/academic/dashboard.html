¿Cómo funciona?

El sistema usa un Modelo Oculto de Markov (HMM) para detectar estados de estrés, motivación, cansancio o desmotivación a partir de patrones académicos.

Evalúa probabilidades de transición entre estados ocultos y emisiones observables mediante el algoritmo de Viterbi.
